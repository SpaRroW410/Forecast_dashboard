# cran-comments

## Update (1.0.3)

This update fixes the test ERROR on all four macOS flavours of the CRAN check results
for 1.0.2 (r-release-macos-arm64, r-release-macos-x86_64, r-oldrel-macos-arm64,
r-oldrel-macos-x86_64; also the M1mac additional issue), which we were asked to
correct before 2026-11-09.

* **Cause:** the test "sarima adapter fits with a seasonal manual order" fitted
  ARIMA(1,1,1)(1,0,0)[52] with `forecast::Arima()` to simulated data drawn without a
  fixed seed. On macOS, `stats::arima()`'s default "CSS-ML" optimisation failed
  with an `optim()` error.
* **Fix in the package:** manually specified ARIMA/SARIMA fits now retry with
  `method = "ML"` and then `method = "CSS"` when an estimation method fails, and only
  raise the error if every method fails. A user-entered order therefore no longer
  stops with an `optim()` error on platforms where one method fails.
* **Fix in the tests:** that test now uses a fixed seed (`withr::local_seed()`), and a
  new test covers the fallback logic directly.

## Notes for reviewers

* `torch` and `prophet` are both optional (Suggests, not Imports). Each is used only for
  its own model (LSTM and Prophet respectively), and only when it is installed. Tests
  that fit either model use `skip_if_not_installed()`, so they are skipped when the
  package is absent. `prophet` pulls in a compiled Stan backend (`rstan`/`StanHeaders`)
  with a documented history of install/check fragility on some platforms; keeping it
  Suggests-only means a check environment without a working Stan toolchain still
  installs and checks forecastsuite cleanly.
  Availability checks (`lstm_available()`, `prophet_available()`,
  `list_models(available_only = TRUE)`) use `system.file(package = ...)` rather than
  `requireNamespace()`, so they only test whether a package is installed and never load
  'torch' (with its native LibTorch libraries) or 'prophet' just to answer that question.
* No test or vignette makes a live network call; the one Google Sheets-related test
  only exercises the pure URL-building helper (`googlesheet_csv_url()`).
* `run_app()` is interactive (launches a Shiny app); its example is guarded with
  `if (interactive())` rather than actually launching the app during checks.
* `man/` is now generated by `roxygen2::roxygenise()` (roxygen2 8.1.0); `NAMESPACE`
  is roxygen-managed too and still deliberately has no `importFrom()`/`import()`
  directives -- every call into another package is fully qualified as `pkg::fn()`.
* NSE column names used unquoted inside `dplyr`/`tidyr` calls (`ds`, `y`, ...),
  the `.data` pronoun, and `self` (used inside a `torch` `nn_module` method body
  in the LSTM adapter) are declared via a single `utils::globalVariables()` call
  in `R/globals.R` to silence the corresponding "no visible binding" NOTE.
